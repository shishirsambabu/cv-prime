# linkedin-queue (data branch)

Data-only branch for the CV Prime LinkedIn content team. Nothing here deploys.

- `queue/<YYYY-MM-DD>-<slug>/` posts waiting to publish (`post.json` + media)
- `published/<YYYY-MM-DD>-<slug>/` posts that went live (with `result.json`)
- `analytics/` daily metrics pulled from LinkedIn

The playbook, team charter and scripts live on `main` under `marketing/linkedin/`.
